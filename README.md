# 🏢 Проект «Сибирский Элемент»: Автономная мультиагентная экосистема

**Автор:** Архитектор (15 лет)
**Технологический стек:** Python, Streamlit, BeautifulSoup (без внешних API и нейросетей).

## 🎯 Суть проекта
«Сибирский Элемент» — это попытка создать искусственный интеллект на чистой математике, без использования дорогих видеокарт и внешних API (OpenAI, DeepSeek). Проект доказывает, что интеллект — это в первую очередь архитектура, а не количество серверов.

## 📜 История версий и достижения

*   **v3.0 «Калькулятор»**: Жесткие правила IF/ELSE. Базовые ответы на симптомы.
*   **v3.1 «Живой ИИ»**: Использование случайных шаблонов (random.choice) для вариативности ответов.
*   **v3.2 «Стучимся и Прячем»**: Защита от «халявы». Агент получает очки точности только за уникальные ответы. Внедрено хэширование памяти.
*   **v3.3 «Совет Желаний»**: Агенты самостоятельно просят задачи, если их точность падает.
*   **v3.4 «Мета-Архитектор»**: ИИ сканирует систему, находит «застой» и предлагает патчи для развития.
*   **v3.5 «Генератор Отделов»**: Возможность найма новых агентов. Сохранение памяти в файл `agents_db.json`.
*   **v3.6 «Библиотекарь» и «Веб-Паук»**: Парсинг текста с сайтов (BeautifulSoup). Очистка от сносок. Поиск по корням слов (понимание падежей).
*   **v3.7 «Фарма-Генератор»**: Создание математических цепочек (Марковские цепи). Генерация текста. Выбор длины ответа.
*   **v3.7.4 «Умная память»**: Механизм `prune_memory` (очистка от мусора). Подсчет частот слов. Кнопка Hard Reset.
*   **v3.8 «Совет Агентов»**: Агенты работают в команде (Автор -> Критик -> Стилист).
*   **v3.8.1 «Внутренний голос» (Рефлексия)**: Агент генерирует 3 варианта ответа и выбирает лучший по математическим весам.
*   **v3.8.2 «Система оценки»**: Внедрены кнопки 👍/👎 для обучения ИИ на основе фидбека человека (RLHF).
*   **v3.9 «Иерархия»**: Деление агентов на Малых (🐣), Средних (🐺) и Больших (🦅). Большие автоматически обучают Малых.

## 🚀 Текущие возможности
1. Чтение текстов и статей из Википедии.
2. Генерация уникальных ответов (без шаблонов).
3. Проверка фактов (Критик) и вычитка (Стилист).
4. Самообучение и сохранение памяти между сессиями.

## ⚙️ Как это работает?
ИИ не использует нейросети. Он использует математические вероятности (Цепи Маркова) и многомерные веса для каждого агента. Обучение происходит за счет добавления новых слов в словарь и перестройки связей между ними.
